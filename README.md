# atividade_permanencia_dados_01

Projeto inicial:
    Este projeto trata-se de uma atividade proposta onde eu criaria o arquivo "input_data.py" e nele faria a programação necessária para receber dados input do terminal (simulando um usuário), depois armazenar esses dados em um arquivo.txt (para permanência desses dados obtidos) e então criar um arquivo read.py que receberia a programação necessária para ler este arquivo.

Projeto estendido:
    Depois tive vontade de estender meus conhecimentos e as habilidades que venho amadurecendo, implementando funcionalidades além do que fora inicialmente pedido e por sua vez já alcançado; Feito isso, transformei uma simples atividade prática em uma pequena estrutura que foi muito divertida de construir, levando a pesquisas, um "bate-tecla" com minha IA sobre um jeito mais simples e limpo de escrever o código e um dia de aprendizado muito produtivo.
